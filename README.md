Nightjar is an original 2.5D architectural stealth heist game across three handcrafted museum wings with raycast vision cones, swivel security cameras, laser tripwires, crawlable air vents, shadow cover alcoves, and an escalating alarm system. Play with keyboard and mouse using priced tactical gadgets (Decoy Coin, Smoke Veil, EMP Jammer) deducted directly from your getaway payout.

## Run it

```sh
node serve.ts
```
